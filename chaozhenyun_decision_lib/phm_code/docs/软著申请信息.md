## 二、软件功能简介（约 300 字，适合申请表「简要说明」栏）

多工况自适应工业设备控制优化系统面向风机、水泵、空压机、机床主轴等工业设备，解决运行参数靠经验固定设定、设备状态判断脱离工况两个问题。系统通过 Modbus TCP、OPC UA、西门子 S7、MQTT 四类工业协议实时接入温度、振动、电流、转速、能耗等运行数据，经五道清洗后自动辨识设备当前所处工况并判定是否稳态；在该工况的历史基线上评估设备健康状态，输出分项指标、总健康分、疑似故障模式、退化趋势与剩余可用时间；结合机理知识、规则推理与历史案例，用代理模型在参数邻域内寻优，生成带完整证据链的运行参数优化建议；建议经七道安全校验后与 PLC、SCADA、DCS 闭环联动，写后回读校验、失败整体回滚；参数生效后系统在观测窗内做前后对比与显著性检验，把验证有效的经验回写代理模型、规则可信度、案例库与工况档案，形成持续自我改进的闭环。系统支持多场景配置化适配，换场景只需更换配置。

## 三、软件功能简介（约 800 字，适合技术材料与项目申报）

### 3.1 解决的问题

工业现场的旋转设备长期存在两个痛点。其一，运行参数靠经验设定后长期不动，而实际负载需求持续变化，导致设备大部分时间运行在非最优点，浪费电能。其二，传统监测系统给每个测点设固定报警阈值，但同一设备在不同负载下各测点的正常范围完全不同，用一套阈值覆盖全工况必然低负载漏报、高负载误报，误报多了系统就被闲置。

### 3.2 技术方案

系统的核心思路是先识别工况，再在该工况的上下文中做健康评估与参数寻优，共实现五项功能。

**设备实时数据接入。** 自行实现 Modbus TCP 的 MBAP 报文封装与 PDU 编解码、西门子 S7 的 TPKT/COTP/S7 三层封装、OPC UA 的轮询读与订阅推送、MQTT 的订阅式接入，覆盖温度、振动、电流、转速、能耗、压力、流量七类信号。地址相邻的测点自动合并批量读，降低通信负担。数据经量程校验、死值检测、尖峰剔除、缺口插补、时标对齐五道清洗，每次修改均可回溯。

**状态识别与健康评估。** 从特征向量中提取工况签名，用马氏距离匹配工况库，超过新颖度阈值即自动建档新工况，工况库自增长且带容量上限与低频淘汰。按变异系数与持续时长判定稳态，非稳态时主动抑制优化。为每个（设备、工况、特征）三元组独立维护稳健基线，健康判断依据是相对本工况基线的标准化偏离而非固定阈值。计算振动、温度、电流、能效四维分项指标并加权融合，同时对最差项施加额外权重避免单一致命项被平均掩盖。用 EWMA 控制图与偏离阈值双通道检测异常，用轴承特征频率在包络谱上定点核对定位故障模式，对健康分历史做回归得到退化速率与剩余可用时间。

**运行参数优化建议。** 融合四路输入：工况快照决定优化上下文与是否允许优化，健康报告决定目标偏向，知识层的规则推理给出方向性动作与硬性禁令、案例库给出历史有效参数，代理模型在参数邻域内定量寻优。规则条件采用受限表达式求值，现场可配置且杜绝代码注入。寻优提供贝叶斯优化、粒子群、NSGA-II 三种算法并支持自动选择，全部使用固定随机种子保证决策可复现。搜索被限制在当前工作点的邻域内，邻域大小由配置比例、参数自身限值与健康度共同决定。产出的建议带参数变更清单、预期收益、置信度、风险等级、证据链与自然语言说明。

**控制系统闭环联动。** 写通道与读通道分开建模，强制具备写前锁定、原值留存、写后回读、写审计四项能力。提供 PLC、DCS、SCADA 三类适配器，只改设定值不接管现场调节回路。所有写操作须通过模式、建议有效性、健康闸门、点位、限幅限速、互锁、频次限流七道检查，采用 fail-closed 原则。执行采用分步下发加逐点回读，任一失败触发逆序整体回滚。四种控制模式支持从只读观察逐级放开到自主闭环。

**执行效果反馈学习。** 参数生效后取下发前后两段等长窗口逐指标对比，用 Welch t 检验判定显著性，避免把噪声当成效果。按期望方向、显著性与非对称惩罚折算标量奖励，再分发到代理模型、规则可信度、案例库、工况档案四个学习去处。内置线性上下文老虎机用于在多个候选调整方向间做在线权衡，探索比例可控。

### 3.3 技术特点

工况归一化的评估基准、工况库自增长、知识与数据双驱动、安全优先的写通道、闭环可验证、全链路可追溯（链式哈希审计账本）。系统仅依赖 NumPy 一个第三方库，不引入 Web 框架、数据库与机器学习框架，可直接部署在边缘计算网关。
